## 🏦 LendCtl Suite

Open-source CLI tools for AI-powered loan origination. 8 tools, 165+ tests, Apache-2.0.

**Why CLI?** [Research shows](https://jannikreinhard.com/2026/02/22/why-cli-tools-are-beating-mcp-for-ai-agents/) CLI tools are 35x more token-efficient than MCP for AI agents.

```bash
npm i -g finctl-cli creditctl mortctl autoloanctl persctl cardctl compctl auditctl
```
